What I took from the review

  • Demote cost; don’t hide it. Sort by cost to find the $64.45 session and its seven subagents.
  • Derive organization before asking for curation. Canonical repositories group across machines; folder groups retain source identity and their full parent path.
  • Broader search needs matching evidence. Try Frosty, source-mapping.csv, or Warm Gray.
  • Explain empty results accurately. Search remote onboarding within Last 7 days, then expand the date range without losing the query.
  • Lead with cross-agent advantages. Concept 2 now carries vendor, machine, repository usage, and resume-readiness structure without returning cost to every card.
  • Keep records honest and stable. Idle and Unknown remain distinct; the staged update moves records only when Refresh is chosen.
