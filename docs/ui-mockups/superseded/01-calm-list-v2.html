Calm List

A hierarchy repair of the default session card. Today's card renders up to eleven competing elements at near-identical weight, and the 36-character session ID is given more horizontal space than the title. This concept removes or demotes everything not used to recognise a session and spends the reclaimed space on what it was, where it ran, when it ran.

Revised after Codex review. Changes in v2:
  • All five status values are now represented — v1 collapsed everything to Active / Waiting / nothing, silently dropping idle and unknown, both of which exist in STATUSES.
  • Unknown sessions have an explicit, honest treatment — remote sessions whose liveness can't be determined are labelled "Unknown", not folded into Inactive and never implied to be complete.
  • Zero-Waiting is the observed reality, so it's the default view — the "Needs you" group renders a defined empty state instead of being hidden, so the layout doesn't shift when a session starts waiting.
  • Data provenance is labelled throughout: observed vs. illustrative.
  • prefers-reduced-motion honoured — v1 animated a pulse with no fallback.
  • Cost stays on the row, demoted rather than deleted — with an optional density setting for people doing spend review.
Data provenance. Sessions, costs, token counts and summaries below are taken from the live local dataset on 2026-09-10 (52 sessions · 2 Active · 41 Inactive · 9 Unknown · 0 Waiting · $296.20). The Waiting card in the second view is illustrative — no session was waiting at inspection time. It is shown because Waiting is the state the design most needs to handle, not because it was observed.

What changed, and why

V2 · FROM REVIEW

Five states, not two

STATUSES defines busy, idle, waiting, inactive and unknown. v1 rendered only Active and Waiting and dropped the rest — which silently erased Idle (process alive, between turns) and Unknown. Inactive remains the unmarked default; the other four are labelled.

V2 · FROM REVIEW

Unknown is never implied to be finished

The 9 Unknown sessions get their own group and an explicit explanation: liveness could not be determined, and they may still be running. Folding them into a "done" bucket would be an unsupported claim about someone's work.

V2 · FROM REVIEW

Empty groups have defined behaviour

Zero sessions were Waiting at inspection. Rather than hiding the group — which makes the list jump the moment one appears — it holds its place with a calm confirmation. Stable layout across refresh was a specific review concern.

V2 · FROM REVIEW

Motion has a fallback

The Active pulse now degrades to a static ring under prefers-reduced-motion. v1 animated unconditionally.

DELETE

The UUID leaves the card face

SessionName is capped at max-w-80 and truncates; SessionId is uncapped. At 900px the title collapses to "Design Coslash …" while the full UUID stays legible. It becomes an 8-char hover chip; the full value stays copyable in the inspector.

DEMOTE

Vendor pill → 3px spine

Claude rust vs. Codex indigo is recognised pre-attentively from a stripe. A pill costs ~70px to say the same thing.

DEMOTE

Cost stops out-shouting the title — but stays

Cost renders at text-base font-bold today, heavier than the session name. It drops to 12px tabular in the fact row. Codex argued for removing it entirely; I keep it, because the $64.45 outlier among $2 sessions is only findable if the number is on the row. A Spend density mode restores prominence for that specific job.

PROMOTE

Repo and branch become a breadcrumb

Location is how people recognise work, but it's currently buried in an 11px grey monospace run of five ·-separated facts.

DELETE

Empty and constant values render nothing

"No summary available" disappears entirely. "This Mac" shows only for genuinely remote sessions. The modality pill ("Codex Work Desktop") is near-constant per user and moves to the inspector.

ADD

Subagents roll up

An expanded rail can triple a card's height. One teal chip keeps the signal; the detail lives in the inspector.
